# OMSA Practicum Fall 2026

Documents, code, and deliverables for Georgia Tech's Online Masters of Science in Analytics (OMSA) Practicum in the fall term of 2026.

This project can involve audio signal processing and machine learning in the context of broiler (chickens raised for meat) health and welfare analysis.
